🧠 Pengantar 1: Statistika Deskriptif vs Inferensial

Dalam duni perkuliahan matematika, statistika dibagi menjadi dua cabang berdasarkan tujuan analisisnya:

  • Statistika Deskriptif: Berfokus pada metode pengumpulan, pengurutan, peringkasan, dan penyajian data kelompok sampel secara informatif (menggunakan tabel frekuensi, grafik, nilai tengah, varians) tanpa melakukan penarikan kesimpulan umum.
  • Statistika Inferensial: Berfokus pada penarikan kesimpulan, perkiraan, estimasi parameter, serta pengujian hipotesis mengenai suatu kondisi populasi berdasarkan hasil analisis kelompok data sampel.

Bentuk Output Tabel frekuensi, diagram grafik, Mean, Median, Modus, Varians. Nilai probabilitas (p-value), uji-t, ANOVA, analisis regresi.

📖 Ukuran Pemusatan Data (Ukuran Tengah)

Ukuran pemusatan digunakan untuk mendeteksi kecenderungan letak titik nilai pusat dari serangkaian kelompok data sampel.

1. Mean (Rata-rata Hitung)

Jumlah total nilai seluruh data amatan dibagi dengan banyaknya ukuran kuantitas sampel data (n):

Mean (x̄) =
x1 + x2 + ... + xn n
=
Σxi n

2. Median (Nilai Tengah Data Tunggal)

Nilai tengah dari barisan data pengamatan setelah diurutkan terstruktur dari terkecil ke terbesar. Nilai letak posisi indeks tengah dihitung dengan rumus: k = (n + 1) / 2

  • Jika sampel berjumlah Ganjil: Median = Xk
  • Jika sampel berjumlah Genap: Median = (Xk + Xk+1) / 2 (di mana nilai k = n / 2)

3. Kuartil (Q1, Q2, Q3)

Nilai pembagi yang mengelompokkan barisan data terurut menjadi 4 bagian sama besar. Letak urutan posisi indeks kuartil ke-i ditentukan dengan:

Posisi Qi =
i * (n + 1) 4

Apabila urutan posisi jatuh pada nilai pecahan desimal, maka dihitung menggunakan pendekatan Metode Interpolasi Linear:

Xqi = Xa + h * (Xb - Xa)
Keterangan: Xa = nilai data sebelum posisi, Xb = nilai data setelah posisi, h = sisa nilai pecahan desimal dari posisi letak kuartil.

4. Modus Data

Unsur variasi nilai amatan yang paling dominan muncul atau mempunyai bobot nilai frekuensi terbesar di dalam kelompok sampel data.

📖 Ukuran Penyebaran Data (Ukuran Variasi)

Ukuran penyebaran digunakan untuk melihat sejauh mana keragaman variasi data menyimpang dari nilai pusatnya.

1. Varians Sampel (s2)

Ukuran keragaman sampel yang dihitung melalui pemanfaatan formula praktis aljabar kuadrat langsung:

s2 =
1 n - 1
* [ Σxi2 -
(Σxi)2 n
]

2. Standar Deviasi Sampel / Simpangan Baku (s)

Dihitung dengan menarik nilai operasi akar pangkat dua dari hasil akumulasi nilai parameter varians sampel:

s = √s2

3. Rentang & Rentang Antar Kuartil

  • Rentang (Range): Nilai Observasi Terbesar - Nilai Observasi Terkecil
  • Rentang Antar Kuartil (Jangkauan IQR): Q3 - Q1
