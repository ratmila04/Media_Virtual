🧠 Pengantar 1: Statistika Deskriptif vs Inferensial

Dalam dunia analisis data, ilmu statistika dibagi menjadi dua pilar utama:

  • Statistika Deskriptif: Metode pengolahan yang bertujuan meringkas, mengurutkan, dan menyajikan data amatan secara informatif (tabel, grafik, rata-rata, simpangan baku) terbatas pada sampel tersebut tanpa menarik generalisasi kelompok luar.
  • Statistika Inferensial: Metode pengujian hipotesis dan estimasi parameter yang bertujuan mengambil keputusan/kesimpulan tentang Populasi besar berdasarkan data sampel acak yang dianalisis.

📏 Pengantar 3: Sifat, Sifat Angka, & Skala Pengukuran Data

A. Sifat Variabel: Kualitatif vs Kuantitatif

  • Data Kualitatif (Kategorik): Data berupa deskripsi kata, label, atau atribut non-numerik yang tidak dapat dihitung matematis secara langsung. Contoh: Jenis Kelamin, Suku Bangsa, Status Pernikahan.
  • Data Kuantitatif (Numerik): Data berupa nilai kuantitatif angka nyata yang dapat dioperasikan secara matematis. Contoh: Tinggi Badan, Jumlah Pendapatan, Usia.

B. Bentuk Angka Kuantitatif: Diskrit vs Kontinu

  • Data Diskrit: Hasil dari aktivitas membilang/menghitung, menghasilkan bilangan bulat positif utuh yang pasti. Contoh: Jumlah anak (3 anak), Jumlah mobil di parkiran (15 mobil).
  • Data Kontinu: Hasil dari aktivitas mengukur, nilainya berada dalam rentang kontinu dan bisa berbentuk pecahan desimal komplit. Contoh: Berat badan (54.75 kg), Kecepatan lari (12.4 detik).

C. Skala Pengukuran Karakter Data (Skala NOIR)

Skala Data Sifat Data Karakteristik Utama Contoh Nyata
1. Nominal Kualitatif Hanya berupa label klasifikasi nama tanpa ada urutan/tingkatan tertentu. Agama, Warna Mata, Jurusan Kuliah.
2. Ordinal Kualitatif Memiliki label kategori yang sudah membentuk tingkatan/peringkat urutan yang jelas. Jarak tidak sama. Juara Kelas (1, 2, 3), Kepangkatan, Jenjang Pendidikan.
3. Interval Kuantitatif Angka kuantitatif berjarak sama, memiliki urutan, tetapi tidak memiliki nilai nol mutlak (0 tetap ada nilainya). Suhu Udara (0 derajat Celsius), Skor IQ, Tahun Masehi.
4. Rasio Kuantitatif Tingkatan tertinggi. Angka berjarak sama, dan memiliki nilai nol mutlak (0 berarti kosong/habis). Tinggi Badan (0 cm berarti tidak ada tinggi), Pendapatan Bulanan, Jarak Rumah.

📖 Ukuran Pemusatan Data (Data Tunggal & Kelompok)

Ukuran pemusatan digunakan untuk menganalisis kecenderungan letak nilai pusat dari sekumpulan data amatan.

1. Mean (Rata-rata Hitung)

A. Data Tunggal: Jumlah total nilai seluruh variabel dibagi ukuran sampel (n):

x̄ =
Σxi n
Keterangan Simbol:
• x̄ : Rata-rata hitung data tunggal
• Σxi : Jumlah total seluruh nilai data (x1 + x2 + ... + xn)
• n : Ukuran sampel atau banyaknya data amatan

B. Data Kelompok: Jumlah hasil perkalian frekuensi kelas dengan titik tengah kelas dibagi total frekuensi:

x̄ =
Σ(fi * xi) Σfi
Keterangan Simbol:
• x̄ : Rata-rata hitung data kelompok
• fi : Frekuensi pada kelas interval ke-i
• xi : Nilai titik tengah kelas interval ke-i, dihitung dengan rumus: (Batas Bawah + Batas Atas) / 2
• Σfi : Total kuantitas frekuensi seluruh data kelompok (Sama dengan total nilai sampel n)

2. Median (Nilai Tengah)

A. Data Tunggal: Diambil dari data urutan ke-k, di mana nilai letak posisi indeks tengah dihitung dengan rumus: k = (n + 1) / 2

B. Data Kelompok: Diambil dari letak kelas median (posisi n/2), lalu dihitung via rumus:

Median = Tb + [
(n / 2) - Fk fm
] * p
Keterangan Simbol:
• Tb : Tepi bawah kelas median (Batas Bawah kelas median dikurangi 0.5)
• n : Total akumulasi frekuensi seluruh data kelompok
• Fk : Frekuensi kumulatif total sebelum memasuki kelas median
• fm : Frekuensi asli yang dimiliki oleh kelas median
• p : Panjang atau rentang interval kelas kelompok

3. Modus & Klasifikasi Kemunculan

A. Data Tunggal: Diambil langsung dari nilai variabel dengan frekuensi kemunculan tertinggi.

B. Data Kelompok: Diambil dari kelas interval dengan frekuensi terbesar, lalu dihitung menggunakan rumus:

Modus = Tb + [
d1 d1 + d2
] * p
Keterangan Simbol:
• Tb : Tepi bawah kelas modus (Batas Bawah kelas dengan frekuensi terbesar dikurangi 0.5)
• d1 : Selisih frekuensi kelas modus dengan frekuensi kelas interval tepat sebelumnya
• d2 : Selisih frekuensi kelas modus dengan frekuensi kelas interval tepat sesudahnya
• p : Panjang atau rentang interval kelas kelompok

📌 Klasifikasi Jenis Data Berdasarkan Jumlah Modus:

  • Amodus: Kelompok data yang tidak memiliki modus sama sekali karena semua nilai muncul sama banyak.
  • Unimodus: Kelompok data yang memiliki tepat satu nilai modus tertinggi.
  • Bimodus: Kelompok data yang memiliki dua nilai modus berbeda dengan frekuensi puncak yang sama.
  • Multimodus: Kelompok data yang memiliki lebih dari dua nilai modus berbeda.

📖 Ukuran Penyebaran Data (Ukuran Variasi)

Ukuran penyebaran digunakan untuk melihat sejauh mana keragaman variasi data menyimpang dari nilai pusatnya.

1. Varians Sampel (s2)

Ukuran keragaman sampel kuadrat yang dihitung menggunakan formula hitung praktis:

s2 =
1 n - 1
* [ Σxi2 -
(Σxi)2 n
]
Keterangan Simbol:
• s2 : Varians (ragam) tingkat sampel
• n : Ukuran sampel atau total banyaknya data amatan
• Σxi2 : Jumlah dari masing-masing nilai data yang telah dikuadratkan terlebih dahulu (x12 + x22 + ...)
• (Σxi)2 : Kuadrat dari total penjumlahan seluruh nilai data amatan

2. Standar Deviasi Sampel / Simpangan Baku (s)

Diperoleh dengan menarik akar pangkat dua dari hasil akumulasi nilai parameter varians sampel:

s = √s2
Keterangan Simbol:
• s : Standar deviasi (simpangan baku) tingkat sampel
• s2 : Hasil nilai perhitungan varians sampel

3. Rentang (Range)

Rentang = Data Terbesar - Data Terkecil
